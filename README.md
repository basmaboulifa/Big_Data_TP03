TP03 (Power BI)Sujet : Analyse Interactive des Données et Visualisation avec Power BI Desktop
Étudiante : Basma Boulifa  
Jeu de données : Pizza Place Sales (order_details.csv) 
Description du Travail :
Dans le cadre du TP03 de Big Data Analytics, nous avons réalisé une analyse interactive des données de ventes à l'aide de Power BI Desktop.
La première étape a consisté à importer le fichier CSV et à vérifier la structure des données via Power Query.   
Ensuite, nous avons conçu un tableau de bord interactif contenant les éléments suivants :Une carte KPI affichant la quantité totale vendue, soit 50 000 unités (50K).
Un graphique en colonnes (Column Chart) présentant la répartition des quantités par type de pizza.
Un graphique en barres (Bar Chart) et un graphique linéaire (Line Chart) illustrant les détails et la dynamique des commandes.
Un segment (Slicer) permettant de filtrer dynamiquement l'ensemble des visuels.
Conclusion et Constats :
L'analyse montre clairement que la pizza de catégorie big_meat_s est la plus vendue et enregistre le plus grand volume de commandes.
L'ajout du Slicer rend l'exploration des données fluide et facilite la prise de décision stratégique.
